# Upwork Portfolio Entry

## Title

Python API Data Sync and Excel Reporting Tool

## Description

Built a Python automation pipeline that imports records from a REST API, normalizes and validates the data, detects duplicate contacts, stores clean records in SQLite, and exports CSV and formatted Excel reports.

The workflow includes request error handling, an offline JSON fallback, structured validation, database persistence, a dashboard worksheet, clean-record and invalid-record sheets, and automated tests.

## Technologies

Python, Requests, SQLite, CSV, OpenPyXL, REST APIs, data validation, GitHub Actions.

## Client value

The tool replaces repetitive API-to-spreadsheet work, improves data consistency, prevents duplicate imports, and creates reusable reports for operations or CRM workflows.
